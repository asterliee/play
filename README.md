# Asterlie

**Star placement puzzle.** Place one star in every row, column and colour region. Stars cannot touch, including diagonally. Every puzzle has exactly one solution.

## Play

Open the GitHub Pages site in any modern browser. On a phone it fills the screen; on a laptop or desktop it runs in a phone-sized frame in the centre of the window. After the first visit it also works offline.

To install on a phone: Safari › Share › Add to Home Screen, or Chrome › menu › Add to Home screen.

## Modes

- Easy, Medium, Hard and Expert
- Daily puzzle, the same for everyone each day
- Ink mode: stars and dots are both permanent, and one incorrect mark ends the puzzle

## Controls

| Action | Input |
|---|---|
| Dot | Tap or click once |
| Star | Tap or click twice |
| Clear | Tap or click three times |
| Dot several cells | Drag across them (start on a dot to erase) |
| Star in Ink mode | Press and hold |

Keyboard: Ctrl+Z / ⌘Z undo, Ctrl+Y / ⇧⌘Z redo, H hint, Esc close.
